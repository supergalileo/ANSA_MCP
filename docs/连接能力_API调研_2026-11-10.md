# ANSA 连接建模 API 调研

> 调研日期：2026-11-10
> 目的：为 402 件独立网格补上焊点/胶接连接，使整车模型可求解
> 数据来源：`ansa_v24.1.2/docs/extending/python_api/html/reference/api_ref_ansa/generated/ansa.connections.html`（403 KB）
> 与本文配套：`交接_连接能力_2026-11-09.md`（数据勘察结论）

---

## 零、一句话结论

**ANSA 有完整的连接 API，`ansa.connections` 模块 60 个函数覆盖「建连接 → 挂零件 → 转 FE → 读清单」全链路。**
本项目缺的两件事，正好各有一个函数专门解决：

| 缺什么 | 用哪个 |
|---|---|
| 焊球坐标已知，但不知道挂哪两个件 | `AutoSetConnectivityInConnections`（带 `search_distance`，自动找附近零件） |
| 连接建好了，不知道怎么变成 CWELD/RBE3 | `RealizeConnections`（`parameters` 字典指定 FE 类型） |

## 一、模块地图（60 个函数，按用途分组）

### 1.1 创建连接实体（3 个，核心）

```python
connections.CreateConnectionPoint(type, position, id, connectivity)   -> Entity
connections.CreateConnectionLine(type, curves, id, connectivity)      -> Entity
connections.CreateConnectionFace(type, faces, id, connectivity, create_new_face) -> Entity
```

### 1.2 挂接零件（自动判两端）

```python
connections.AutoSetConnectivityInConnections(connections, ...)   -> None
connections.ConvertConnectivity(connections, connectivity_mode, search_nearest_dist)
connections.GroupConnectionsByConnectivity(connections)          -> list
connections.ReplaceConnectivity(old, new, connections, ...)
```

### 1.3 转成 FE（出单元）

```python
connections.RealizeConnections(connections, parameters)   -> int   # 返回成功数，全失败返回 0
connections.ReApplyConnections(connections)               -> int
connections.EraseConnectionFeRep(connections)             -> int
connections.ConvertConnectionsToGeometry(connections, part)-> list
connections.ConvertFeRepToConnection(entities, convert_type, ...)
```

### 1.4 读 / 写连接清单

```python
connections.ReadConnections(filetype, filename, group_name, offset_val)  -> int   # 0 = 失败
connections.OutputConnections(connections, filetype, filename)           -> int
```

`filetype` 支持 `"XML"`、`"VIP"`（传错时 ANSA 会在异常里列出全部合法值）。

### 1.5 设置与检查

```python
connections.GetAllConnectionSettings(connection)      -> dict
connections.GetConnectionSettings(connection, parameters)
connections.AssignConnectionSettings(connections, parameters)
connections.RemoveDoubleConnections(connections, tolerance, equivalent_connectivity, keep_id, mode)
connections.FindDuplicateConnections(c1, c2, point_distance_method, ...)
connections.CenterConnections(connections)
connections.FindConnectionCharacteristics(connections, search_pattern, average_angle)
```

### 1.6 从几何反推连接

```python
connections.ConvertTubesToConnections(connection_type, input_faces, connections, matched_faces, ...)
connections.OpenCreateConnectionsOnFlanges()      # 从翻边建连接（GUI）
connections.ConvertConnectionsToGeometry(connections, part)
```

`ConvertTubesToConnections` 只认**管状**几何，本项目焊点是球体，用不上。

### 1.7 装配场景（整批规则，暂不需要）

`CreateNewAssemblyScenario` / `CreateNewAssemblyRule` / `RunAssemblyScenario` / `RunAllAssemblyScenarios` /
`ReadAssemblyScenario` / `DistributeAllItemsToAssemblyScenarios` / `AddFilterToAssemblyRule(s)` 等 12 个。
适合"按规则批量给上千个零件建连接"，本阶段用不到，先记着有这条路。

### 1.8 GUI 桥接（batch 模式下不可用）

`OpenConnectionManager` / `OpenTemplateManager` / `OpenCreateConnectionsOnFlanges`
—— 都是 `-> bool` 的开窗函数，`-nogui` 跑不了。

## 二、11 种连接类型

文档里出现的全部 `_Type` 值：

| 类型 | 几何形态 | 对应本项目焊球里的 |
|---|---|---|
| `SpotweldPoint_Type` | 点 | `SPOTWELD_2T` / `3T` / `4T`（8×8×8 球） |
| `SpotweldLine_Type` | 线（连续点焊链） | — |
| `SeamLine_Type` | 线 | `SEAM`（5 个）、`LASER_WELD`（166 个细长条） |
| `AdhesiveLine_Type` | 线 | `ADHESIVE`（211 个长条面） |
| `AdhesiveFace_Type` | 面 | `ADHESIVE` 里较宽的那些 |
| `Bolt_Type` | 点 + 孔 | — （紧固件 129 件暂不建连接） |
| `Rivet_Type` | 点 | `RIVET`（326 个，8×8 球） |
| `Screw_Type` | 点 + 孔 | — |
| `GumDrop_Type` | 点 | 可能是 `FOAM`（42 个块） |
| `Hemming_Type` | 线 | 包边，本项目未见 |
| `Robscan_Type` | 线 | 可能是 `LASER_WELD` |

**注意**：`AutoSetConnectivityInConnections` 明确不支持 `Hemming_Type` 和 `AdhesiveFace_Type`，
这两类的连接要手工指定两端。

## 三、创连接：三件套

### 3.1 点连接（点焊 / 铆钉 / 螺栓 / 点胶）

```python
xyz = [-822.0, 531.0, 259.0]
part_ids = ["999999, #1", "888888"]      # 零件ID, #propertyID
cnctn = connections.CreateConnectionPoint("SpotweldPoint_Type", xyz, 100999, part_ids)
base.SetEntityCardValues(constants.NASTRAN, cnctn, {"D": 3})    # 焊点直径 3
```

- `type`：`SpotweldPoint_Type` / `Bolt_Type` / `GumDrop_Type` / `Rivet_Type` / `Screw_Type`
- `position`：`[x, y, z]` 浮点列表
- `id`：连接 ID（可省略，ANSA 自动分配）
- `connectivity`：两端零件的字符串列表
- 返回 `None` 表示失败
- 卡片字段：`D` = 直径

### 3.2 线连接（缝焊 / 胶接）

```python
curves = [base.GetEntity(constants.NASTRAN, "CURVE", 166)]
part_ids = ["999999, #1", "888888"]
cnctn = connections.CreateConnectionLine("AdhesiveLine_Type", curves, 100122, part_ids)
base.SetEntityCardValues(constants.NASTRAN, cnctn, {"W": 2, "H": 1.5})   # 宽 2，高 1.5
```

- 卡片字段：`W` = 宽度，`H` = 高度

### 3.3 面连接（宽胶接）

```python
faces = [base.GetEntity(constants.NASTRAN, "FACE", 15)]
cnctn = connections.CreateConnectionFace("AdhesiveFace_Type", faces, 222, part_ids)
```

### 3.4 connectivity string 的两种写法

**手写字符串**（快，但要自己知道 ID）：

```python
part_ids = ["999999, #1", "888888"]
#            ↑ 零件 module id  ↑ property 矩阵编号（可省）
```

**从实体生成**（推荐，最不容易错）：

```python
p1 = [base.GetEntity(ansa.constants.NASTRAN, "ANSAPART", 999999),
      base.GetEntity(ansa.constants.NASTRAN, "PSHELL", 1)]
p2 = [base.GetEntity(ansa.constants.NASTRAN, "ANSAPART", 888888)]
part_ids = [connections.EntsToConnectivityString(p1),
            connections.EntsToConnectivityString(p2)]
```

反向：`connections.ConnectivityStringToEnts(s)` 把字符串解回实体。

**多层板**（三层板点焊）就是 `part_ids` 里放 3 个元素。

## 四、转 FE：RealizeConnections

```python
connections.RealizeConnections(
    cnctns,
    {
        "AdhesiveLine_Type": "RBE3-CELAS1-RBE3",
        "AdhesiveLine_RBE3-CELAS1-RBE3_Pinflags": "12",
        "SpotweldPoint_Type": "RBAR",
    },
)
```

- `parameters` 是**扁平字典**，key 有两种：
  - `<类型>_Type` → FE 实现方式
  - `<类型>_<FE类型>_<属性名>` → 该实现方式的细项
- 传 `{}` 用全默认
- 返回：成功数；**全失败返回 0**

**默认 FE 实现**（文档明确）：

| 连接类型 | 默认 FE |
|---|---|
| `SpotweldPoint_Type` | `RBE2` |
| `AdhesiveLine_Type` | `RBE3-HEXA-RBE3` |

可用 FE 实现（从示例里看到的）：`RBE2`、`RBAR`、`RBE3-HEXA-RBE3`、`RBE3-CELAS1-RBE3`。
完整清单用 `connections.GetAllConnectionSettings(某条连接)` 取。

**对本项目的含义**：点焊默认出 `RBE2`（刚体），比 `CWELD` 硬。
如果要做焊点强度，得换成弹簧/实体单元组合；只做整车刚度/模态，`RBE2` 是可接受的常见做法，
但**必须在报告里写明这是等效连接**。

## 五、AutoSetConnectivityInConnections —— 解决「不知道挂哪两个件」

这是本项目最关键的一个函数。完整签名：

```python
connections.AutoSetConnectivityInConnections(
    connections,
    filter_visible=False,
    output_mode='pid',              # 'pid' | 'moduleid' | 'groups'
    search_faces=True,
    search_shells=True,
    search_solids=False,
    search_tubes=False,
    search_projection=True,         # Bolt 专用
    search_holes=False,             # Bolt 专用
    use_hole_shape=True,
    use_hole_proximity=True,
    hole_proximity_distance=100.0,
    hole_proximity_angle=10.0,
    match_hole_params='any',
    search_distance=5.0,            # ★ 搜索半径，最关键
    use_settings=False,
    search_on_direction=False,
    search_from=-1.0,
    search_to=1.0,
    find_nearest=2,                 # ★ 找最近几个
    find_up_to=2,                   # ★ 最多几个
    find_exactly=2,                 # ★ 正好几个
    between_parts=False,
    clear_connectivity=True,        # ★ 先清空再重设
    tubes_feature_line_angle_limit=30.0,
    consider_part_hierarchy=False,
) -> None
```

文档原文：

> This function **clears the connectivity of each connection and then sets a new connectivity**
> based on the user's parameters. It supports all connection types except hemmings and adhesive faces.

**三个参数决定成败**：

| 参数 | 本项目取值建议 | 理由 |
|---|---|---|
| `search_distance` | 先 2.0，再逐步放大到 5.0 | 焊球直径 8mm，球心到壳的距离≈半壁厚+间隙，2mm 起步够 |
| `find_nearest` / `find_up_to` | 2（两层板）/ 3（三层板）/ 5（缓冲器那种 5 层叠装） | 与焊点类型匹配 |
| `between_parts` | `False` | 同零件的自焊也要能挂上 |

**注意 `clear_connectivity=True` 是默认值** —— 调这个函数会**覆盖**已有 connectivity。
如果要保留手工指定的两端，得传 `False`。

**它能解决什么**：把 `CreateConnectionPoint` 建出来、`connectivity` 留空的点焊，
按坐标自动找最近的两个零件挂上。这正是本项目 5 780 个焊球最需要的能力。

## 七、与本项目数据的对接方案

现有资产（`car3/_tools/conn_entities.json`，6 943 条）：

| 已知 | 未知 |
|---|---|
| 每个焊球的中心坐标（XYZ，mm） | 该球连的是哪两块板 |
| 类型（点焊 2T/3T/4T、铆钉、缝焊、胶接…） | 直径（几何 8mm，但设计值未知） |
| 中面网格已在 `02_Skin成功` / `04_Casting成功` | 层数对应的零件顺序 |

### 建议流程

```python
# 1. 把 402 个网格装进同一个库（坐标已验证可直接对齐）
# 2. 逐个焊球建连接点（connectivity 先留空 []）
for b in balls:
    if b["type"].startswith("SPOTWELD"):
        connections.CreateConnectionPoint("SpotweldPoint_Type", b["xyz"], b["id"], [])
    elif b["type"] == "RIVET":
        connections.CreateConnectionPoint("Rivet_Type", b["xyz"], b["id"], [])

# 3. 自动挂零件（关键一步）
connections.AutoSetConnectivityInConnections(
    spot_list,
    search_distance=2.0,
    find_nearest=2, find_up_to=3, find_exactly=2,
    between_parts=False,
    clear_connectivity=True,
)

# 4. 统计挂接结果 —— 这一步不能省
#    有多少找到 2 个件？多少只找到 1 个？多少一个都没找到？
#    没挂上的必须逐条列出，不能静默补

# 5. 转 FE
n = connections.RealizeConnections(spot_list, {"SpotweldPoint_Type": "RBE2"})

# 6. 验收
#    自由模态刚体模态数必须 = 6
```

### 关键风险

1. **`search_distance` 是全模型一个常数**，但实际间隙分布很宽。建议做**距离扫描**：
   0.5 / 1 / 2 / 5 / 10，看找到 2 个件的比例怎么变，再定值。
2. **`find_up_to=3` 会漏掉 5 层叠装的点**。`A##########` 那种件要单独用 5。
3. **`clear_connectivity=True` 会覆盖**，调试时先用 `False` 对比。
4. **`RBE2` 是刚体连接**，会让局部刚度偏高。做模态可以，做焊点强度不行。
5. **`AdhesiveFace_Type` 和 `Hemming_Type` 不被 `AutoSetConnectivity` 支持**，
   胶接的宽面要手工指定两端。

## 八、实测结果（2026-11-10，ANSA 24.1.2，`-nogui -nolauncher` batch 模式）

```
ansa.connections 可 import，dir() 报 81 个公开名
8 个核心函数全部存在：CreateConnectionPoint / CreateConnectionLine / CreateConnectionFace
                     / RealizeConnections / AutoSetConnectivityInConnections
                     / ReadConnections / OutputConnections / GetAllConnectionSettings
```

**`CreateConnectionPoint` 在 batch 模式下能建出实体**：

```python
base.Open("02_Skin成功/A##########.ansa")
c = connections.CreateConnectionPoint("SpotweldPoint_Type", [0, 0, 0], 987654, [cstr, cstr])
# → Entity, _id = 987654, card D = 0.0（默认直径）
```

**但 `EntsToConnectivityString([part])` 返回 `"-1"`**：

```
part_id = 1, part_name = "B####_A##########"  →  conn_str = "-1"
```

`-1` 是「该 part 没有 module id」的哨兵值。connectivity string 用的是 **module id / MID**，
不是 ANSA 内部的 entity id。从 `.ansa` 直接打开时 part 往往没有分配 MID。

**这对流程的影响**：
- 文档示例里的 `"999999, #1"` 是 MID，不是 `Entity._id`
- 要么先给 part 分配 MID，要么**跳过手工 connectivity，直接用 `AutoSetConnectivityInConnections`**
  （它支持 `output_mode='pid'`，按 PID 挂，不依赖 MID）

后者更省事，也是本项目应该走的路。
